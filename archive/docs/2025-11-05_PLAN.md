# Work Plan: 2025-11-05

## Context

Last session (2025-11-04) achieved a breakthrough with Experiment 2L, reaching r=0.9076 for predicting 3-edge pathway CbGiGpPW counts by using non-linear aggregation of 2-hop predictions. This broke through the r=0.80 ceiling observed with compositional models.

The key innovation was extracting 25 aggregation features (sums, means, stds, maxs of 2-hop predictions, degree distributions, etc.) instead of just 2 features (composition_sum, n_intermediates). Simple linear regression on these rich features outperformed Random Forest and Gradient Boosting.

Today's goal is to validate that this approach generalizes to other metapaths and scales to longer paths (4-5 edges).

## Scientific Hypotheses

### Hypothesis 1: Generalization Across 3-Edge Metapaths

The non-linear aggregation approach will generalize across different 3-edge metapaths because:
- Feature extraction captures permutation-invariant distributional information (degree distributions, prediction statistics)
- 2-hop models work well (r>0.95) for all edge types
- Aggregation features don't depend on specific edge semantics, only on distributional properties

### Hypothesis 2: Hierarchical Scaling to Longer Paths

Cascading models (using 3-hop predictions as features for 4-hop models) will maintain accuracy because:
- High-quality intermediate predictions (r=0.9076) reduce error propagation
- Each level adds only one layer of approximation error
- Aggregation features capture uncertainty at each level

### Hypothesis 3: Linear Scaling with Path Length

The approach scales linearly with path length because:
- Each additional edge requires one new 2-hop model (O(1) per edge type pair)
- Feature extraction requires one pass over intermediates regardless of path length
- No exponential growth in model complexity

## Priority 1: Test Additional 3-Edge Metapaths

### Motivation

Experiment 2L only tested CbGiGpPW (Compound-binds-Gene-interacts-Gene-participates-Pathway). We need to confirm the non-linear aggregation approach works for other 3-edge metapaths with different edge types and node types.

### Candidate Metapaths

Test the Experiment 2L approach on 3-5 additional 3-edge metapaths with diverse characteristics:

**Metapath selection criteria**:
1. Different edge type combinations (not just CbG→GiG→GpPW)
2. Different node type combinations
3. Varying intermediate node counts (some with many intermediates, some with few)
4. Different degree distributions

**Candidate metapaths** (in priority order):

1. **CtDaG** (Compound-treats-Disease-associates-Gene)
   - Medical relevance: Compound→Disease→Gene pathway
   - Different edge semantics than CbGiGpPW
   - Likely fewer intermediates (diseases) than genes

2. **CrCbG** (Compound-resembles-Compound-binds-Gene)
   - Tests compound-compound similarity relationships
   - Intermediate is same node type as source

3. **DaGiGpPW** (Disease-associates-Gene-interacts-Gene-participates-Pathway)
   - Similar structure to CbGiGpPW but starts with Disease
   - Can reuse GiG and GpPW 2-hop models from yesterday

4. **CbGpBP** (Compound-binds-Gene-participates-BiologicalProcess)
   - Similar to CbGiGpPW but target is BiologicalProcess not Pathway
   - Tests generalization to different target node type

5. **GiGpPWpG** (Gene-interacts-Gene-participates-Pathway-participates-Gene)
   - All gene endpoints
   - Pathways as intermediates (different directionality)

### Implementation

For each metapath:

1. Load or train required 2-hop models (reuse where possible)
2. Sample 10,000 source-target pairs (stratified: 50% with paths, 50% random)
3. Extract 25 aggregation features per pair
4. Train on K=1, validate on mean(perms 11-20)
5. Test Linear-All, RandomForest, GradientBoosting models
6. Record r, MAE, and top 5 feature importances

**Expected outcome**: If approach generalizes, should see r>0.85 for all metapaths. If r<0.80 for any metapath, investigate what's different (degree distributions, intermediate counts, etc.).

### Script Naming

Create `test_src/test_3edge_metapath_generalization_exp2l_extended.py` that:

- Creates comparison visualization showing all tested metapaths

## Priority 2: Test 4-Edge Pathway Prediction

### Motivation

Validate the hierarchical scaling approach works in practice. Theory says we can build 4-edge models by combining 3-hop and 2-hop predictions, but this needs empirical confirmation.

### Candidate 4-Edge Metapaths

1. **CbGiGpPWpG** (Compound→Gene→Gene→Pathway→Gene)
   - Natural extension of CbGiGpPW
   - Can reuse trained models from yesterday
   - Intermediates are (Gene, Pathway) pairs

2. **CtDaGiGpPW** (Compound→Disease→Gene→Gene→Pathway)
   - Combines multiple biological relationships
   - Tests whether cascading models accumulates error

### Hierarchical Implementation for CbGiGpPWpG

**Phase 1: Train/load 2-hop models**
- CbGiG model (already trained)
- GiGpPW model (already trained)
- PWpG model (need to train)

**Phase 2: Train 3-hop aggregation model**
- CbGiGpPW model (Experiment 2L, already trained)

**Phase 3: Extract 4-hop features**

For each Compound-Gene pair (C, G_target):
- Identify intermediate pathways: PW where both CbGiGpPW[C, PW] > 0 and PWpG[PW, G_target] > 0
- For each intermediate PW:
  - Get CbGiGpPW prediction from 3-hop model (not composition)
  - Get PWpG prediction from 2-hop model
  - Compute product and other interaction terms

Extract 25+ aggregation features:
- Sum, mean, std, max, min of CbGiGpPW predictions
- Sum, mean, std, max, min of PWpG predictions
- Sum, mean, std, max, min of products
- Count of intermediate pathways
- Degree statistics of intermediate pathways
- Endpoint degrees (deg_C, deg_G_target)
- New features:
  - Variance of intermediate pathway degrees
  - Correlation between CbGiGpPW and PWpG predictions (if enough intermediates)
  - Ratio of max to mean predictions
  - Sum of squared predictions

**Phase 4: Train aggregation model**
- Train on K=1, validate on mean(perms 11-20)
- Compare Linear, RandomForest, GradientBoosting
- Analyze whether prediction quality degrades with path length

**Expected outcome**: If hierarchical approach works, should see r>0.80 for 4-edge paths. Ideal would be r>0.85. If r drops significantly below 0.80, this indicates error accumulation in cascading models.

### Key Question

Does using the 3-hop model prediction (r=0.9076) instead of composition perform better than using composition? This tests whether high-quality intermediate predictions reduce error accumulation.

**Comparison experiment**: Test two approaches for 4-edge prediction:
1. **Hierarchical**: Aggregate 3-hop model predictions + 2-hop predictions
2. **Flat composition**: Aggregate 2-hop × 2-hop × 2-hop products directly (skipping 3-hop model)

If hierarchical outperforms flat, this validates the cascading approach.

## Priority 5: Optimize Neural Network Architecture

### Motivation

Experiment 2L's neural network achieved only r=0.6215, far below linear regression (r=0.9076). With proper tuning, NNs might achieve r>0.95.

### Approach

Systematic hyperparameter search for the neural network:

**Architecture variations**:
1. Shallower: 2 hidden layers (64→32) instead of 3
2. Wider: More neurons per layer (128→64→32)
3. Skip connections: ResNet-style architecture
4. Batch normalization between layers
5. Different activation functions (LeakyReLU, ELU)

**Training variations**:
1. More epochs: 200-500 instead of 100
2. Learning rate: Test {0.0001, 0.0005, 0.001, 0.005}
3. Batch size: Test {16, 32, 64, 128}
4. Optimizer: Test Adam, AdamW, SGD with momentum
5. Regularization: Test L1/L2 penalties, dropout rates {0.1, 0.2, 0.3, 0.5}

**Training procedure**:
- Use early stopping on validation loss
- Track validation r every 10 epochs
- Save best model by validation r (not training loss)

**Expected outcome**: If properly tuned, NN should match or exceed linear regression. If NN still underperforms, this suggests the problem is fundamentally linear in the aggregation feature space.

## Expected Challenges

1. **Sparse metapaths**: Some 3-edge or 4-edge metapaths may have very few positive examples, making sampling difficult.

2. **Computational cost**: Feature extraction requires enumerating intermediates for each pair. With 10,000 pairs × multiple metapaths, this could take hours.

3. **Error accumulation**: Cascading models for 4-5 edge paths may accumulate errors, degrading r.

4. **Overfitting with K>1**: Training on multiple permutations may overfit if validation permutations are too similar.

5. **Memory constraints**: Storing intermediate predictions for 4-5 edge paths could require substantial memory.

## Contingency Plans

**If 4-edge hierarchical approach fails (r<0.70)**:

- Investigate whether intermediate predictions are poorly calibrated

**If K>1 doesn't improve r**:
- Check if validation target correlation actually increases with K
- Verify no data leakage (training and validation permutations are disjoint)
- Consider that K=1 may already capture sufficient information
