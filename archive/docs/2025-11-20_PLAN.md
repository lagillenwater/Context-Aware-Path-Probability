## Executive Summary

This document outlines a comprehensive experimental plan to validate the DWPC p-value calculation methodology used in the 2023 Hetnet Connectivity Search paper (Himmelstein et al., GigaScience 2023). Our preliminary analyses have revealed that longer paths and higher degree node combinations exhibit greater variation across permuted networks. This observation raises a critical question: how can significant p-values be reliably obtained in precisely those scenarios where null distributions show the highest variance?

This experiment will use permutation-based ground truth to assess whether DWPC p-value calculations correctly identify significant connectivity patterns while controlling for degree effects and path length. We will calculate DWPCs for random paths in two scenarios: (1) a "null test" using permutation 0 as observed data vs permutations 1-20 as null (expected: uniform p-values), and (2) a "positive control" using the true Hetionet graph vs permutations 1-20 as null (expected: potentially enriched low p-values if biological signal exists). Results will be stratified by degree combination and path length.

## Background and Motivation

### DWPC P-Value Methodology from Himmelstein et al. 2023

The 2023 paper introduces a sophisticated approach for computing p-values for Degree-Weighted Path Counts (DWPCs):

1. **Degree-Weighted Path Count (DWPC)**: A metric that quantifies connectivity between source and target nodes along a metapath, downweighting paths through high-degree nodes using a damping exponent (w=0.5 in the paper).

2. **Permutation-Based Null Distribution**: They generated 200 degree-preserving permuted networks using the XSwap algorithm. Each permutation maintains node degree sequences but randomizes edge placement.

3. **Degree-Grouping Strategy**: A critical innovation is grouping null DWPCs by source degree and target degree. For a given metapath, all node pairs with the same (source_degree, target_degree) combination share a null distribution. This increases the effective sample size dramatically (e.g., from 200 permutations to potentially thousands of null DWPC values).

4. **Gamma-Hurdle Distribution**: They model null DWPCs using a zero-inflated gamma distribution:
   - The "hurdle" component captures the proportion of zero DWPCs (no paths exist)
   - The "gamma" component models nonzero DWPC values
   - Parameters (lambda, alpha, beta) are estimated using method of moments

5. **P-Value Calculation**: For an observed DWPC, they compute the right-tail probability under the fitted gamma-hurdle null distribution. This indicates whether the observed connectivity exceeds what would be expected by chance given the node degrees.

### Our Observation: Variance Increases with Path Length and Degree

Our previous analyses (notebooks 17, 17b, and related work) have documented that:

1. **Path Length Effect**: Longer paths (length 4-5) show substantially more variation across permutations compared to shorter paths (length 2-3).

2. **Degree Effect**: Higher degree node combinations exhibit greater variation in path counts and DWPCs across permutations.

3. **Compositional Failure**: Our notebook 17 showed that compositional calculations (multiplying edge probabilities) fail to predict path probabilities accurately (r=0.35), particularly for longer paths.

### The Central Paradox

This creates an apparent paradox: if null distributions have higher variance for long paths and high-degree nodes, one might expect:

- **Wider confidence intervals**: More variation should make it harder to detect significance
- **Higher p-values**: Observed values would need to be more extreme relative to a wider null distribution
- **Reduced power**: Ability to detect true connectivity would decrease

Yet the 2023 paper successfully identifies significant connectivity patterns across diverse metapaths, including longer ones. This suggests either:

1. The gamma-hurdle modeling effectively captures the increased variance
2. True biological connectivity patterns are sufficiently strong to overcome the increased variance
3. The degree-grouping strategy provides sufficient statistical power
4. There may be subtle issues with how variance scaling affects p-value reliability

### Research Questions

This experiment aims to answer:

1. **Calibration Question**: Are DWPC p-values properly calibrated? When we use one permutation as "truth" and others as null, do we get the expected distribution of p-values (uniform under the null hypothesis)?

2. **Degree Stratification Question**: Does p-value reliability vary systematically by degree combination? Are low-low degree pairs more reliable than high-high?

3. **Path Length Question**: Does p-value reliability degrade with path length? Are length-3 metapaths more reliable than length-5?

4. **Variance Relationship**: How does the observed variance in null distributions relate to p-value significance? Do higher-variance degree groups show systematically different p-value patterns?

5. **Sample Size Question**: How many permutations are needed for reliable p-values? Does this requirement vary by degree and path length?

6. **Comparison to Paper**: When we scale to 200 permutations, do our results align with the connectivity patterns reported in the paper?

## Experimental Design

### Overview

We will conduct a permutation-based validation study that treats one permutation as "observed data" and uses others to compute null distributions and p-values. This allows us to know ground truth: permutation 0 is drawn from the same distribution as permutations 1-20, so we can evaluate whether the p-value methodology correctly reflects this.

### Phase 1: Proof of Concept (Permutations 0-20)

#### Step 1: Metapath Selection

Select representative metapaths across path lengths:

**Length 3 (baseline)**:
- CbGpPW (Compound-binds-Gene-participates-Pathway)
- CtDaG (Compound-treats-Disease-associates-Gene)
- GiGaD (Gene-interacts-Gene-associates-Disease)

**Length 4 (medium complexity)**:
- CbGpPWpG (Compound-binds-Gene-participates-Pathway-participates-Gene)
- CtDaGiG (Compound-treats-Disease-associates-Gene-interacts-Gene)

**Length 5 (high complexity)**:
- CbGpPWpGaD (Compound-binds-Gene-participates-Pathway-participates-Gene-associates-Disease)

Selection rationale: These metapaths span different biological relationships, have varying path density, and include the gene-disease associations central to biomedical applications.

#### Step 2: Degree Category Definition

For each metapath, we will define degree categories based on quantiles of the degree distribution:

- **Low**: 0-33rd percentile of degree
- **Medium**: 33rd-67th percentile
- **High**: 67th-100th percentile

This creates 9 degree combination categories:
1. Low-Low
2. Low-Medium
3. Low-High
4. Medium-Low
5. Medium-Medium
6. Medium-High
7. High-Low
8. High-Medium
9. High-High

Rationale: Quantile-based categories ensure balanced sample sizes across categories and adapt to the specific degree distribution of each metapath. This differs from arbitrary thresholds and ensures we can detect category-specific effects.

#### Step 3: Path Sampling Strategy

For each metapath and degree category combination:

1. **Identify eligible node pairs**: Find all source-target pairs in permutation 0 whose degrees fall in the specified category.

2. **Filter for connectivity**: Retain only pairs with at least one path in permutation 0 (nonzero path count).

3. **Stratified sampling**: Sample N=100 paths per category, or all paths if fewer than 100 exist.

4. **Record metadata**: Store source node, target node, source degree, target degree, observed path count, observed DWPC.

Rationale: Stratified sampling ensures representation across all degree combinations. Filtering for connectivity focuses our analysis on cases where p-values are most relevant (you cannot assess significance of zero connectivity). Sampling 100 paths balances statistical power with computational feasibility.

#### Step 4: DWPC Calculation

For each sampled path, calculate DWPCs in two experimental scenarios:

**Scenario A: Null Test (Permutation 0 as Observed)**

1. **Observed DWPC**: Calculate DWPC in permutation 0 using hetmatpy with damping exponent w=0.5 (matching the paper).

2. **Null DWPCs**: Calculate DWPC for the same source-target pair in permutations 1-20.

3. **Degree-grouped null DWPCs**: Aggregate null DWPCs across all permutations and all node pairs with the same (source_degree, target_degree) combination.

**Scenario B: Positive Control (True Hetionet as Observed)**

1. **Observed DWPC**: Calculate DWPC in the true Hetionet v1.0 (unpermuted network) using hetmatpy with damping exponent w=0.5.

2. **Null DWPCs**: Calculate DWPC for the same source-target pair in permutations 1-20.

3. **Degree-grouped null DWPCs**: Same aggregation strategy as Scenario A. Note that degrees are measured in the true Hetionet, so degree categories are identical between scenarios.

This yields for each scenario:
- 1 observed DWPC value
- ~20 null DWPC values for the specific node pair
- Potentially 100s-1000s of degree-grouped null DWPCs

Rationale for two scenarios: Scenario A tests calibration under the null hypothesis (permutation 0 is drawn from the same distribution as the null). Scenario B tests whether the methodology can detect genuine biological signal (true Hetionet may contain non-random connectivity patterns that differ from permuted networks).

#### Step 5: P-Value Computation

Implement the paper's exact methodology following Himmelstein et al. 2023:

**Method A: Gamma-Hurdle P-Values** (primary method, matches paper exactly)

1. **Fit gamma-hurdle distribution to degree-grouped null DWPCs** using method of moments (as specified in the paper, page 8):

   Let N = total number of degree-grouped null DWPCs
   Let n = number of nonzero degree-grouped null DWPCs
   Let x_i = nonzero DWPC values

   Estimate parameters using Bessel's correction for second moment:

   ```
   lambda_hat = n / N

   alpha_hat = (n - 1) * sum(x_i) / [n * sum(x_i^2) - (sum(x_i))^2]

   beta_hat = (n - 1) / n * [n * sum(x_i) / [n * sum(x_i^2) - (sum(x_i))^2]]
   ```

   Where:
   - lambda represents the proportion of nonzero DWPCs (hurdle component)
   - alpha and beta are the shape and rate parameters of the gamma distribution

2. **Calculate p-value** as the right-tail probability under the gamma-hurdle distribution:

   ```
   p = P(X >= observed_DWPC) = (beta^alpha / Gamma(alpha)) * integral from observed_DWPC to infinity of x^(alpha-1) * exp(-beta*x) dx
   ```

   Use scipy.stats.gamma(alpha, scale=1/beta).sf(observed_DWPC) for computation.
   If observed_DWPC = 0, p-value = 1.

3. **Handle edge cases** (as described in paper, page 10):
   - If observed DWPC = 0: p-value = 1
   - If all null DWPCs are zero but observed > 0: p-value = 0
   - If all nonzero null DWPCs have same value (SD = 0): use empirical p-value

**Method B: Empirical P-Values with Degree-Grouping** (validation method)
1. Compute empirical p-value: (# null DWPCs >= observed) / (total # null DWPCs)
2. Use degree-grouped null DWPCs for larger sample size
3. This is non-parametric and doesn't assume gamma distribution

**Method C: Direct Empirical** (baseline, no degree-grouping)
1. Use only the ~20 null DWPC values from the same node pair (across permutations 1-20)
2. Compute: (# null DWPCs >= observed) / 20
3. This tests whether degree-grouping assumption is necessary

Rationale: Method A exactly replicates the paper's approach. Comparing methods allows us to assess the impact of degree-grouping and parametric modeling. Method C provides a direct, model-free baseline. Method B isolates the effect of degree-grouping from parametric assumptions.

#### Step 6: Null Distribution Characterization

For each degree category and metapath:

1. **Sample size**: Count of degree-grouped null DWPCs
2. **Zero proportion**: Fraction of null DWPCs that are zero
3. **Nonzero statistics**: Mean, median, SD, IQR of nonzero null DWPCs
4. **Gamma parameters**: Fitted alpha and beta
5. **Goodness of fit**: QQ plots, Kolmogorov-Smirnov test for gamma fit

### Phase 2: Full-Scale Validation (Permutations 0-200)

If Phase 1 shows promising results, extend to all 200 permutations:

1. Use permutations 0-19 as "observed" (20 independent test sets)
2. Use remaining permutations as null
3. Sample more paths per category (N=500)
4. Include all metapaths of length ≤3 from the paper
5. Run on HPC with job arrays

Rationale: Using 20 different test permutations provides independent replication. The larger sample size enables more robust conclusions. Including all metapaths allows comprehensive assessment of methodology.

## Analysis Plan

### Primary Analyses

#### Analysis 1: P-Value Calibration Under the Null

**Hypothesis**: If the p-value methodology is properly calibrated, p-values should be uniformly distributed when the "observed" data comes from the same distribution as the null.

**Test**:
1. For each sampled path, we have a p-value
2. Under correct calibration, these p-values should follow Uniform(0,1)
3. Test uniformity with:
   - Histogram of p-values (should be flat)
   - Kolmogorov-Smirnov test for uniformity
   - QQ plot against uniform distribution

**Expected outcome**:
- Well-calibrated: ~5% of p-values below 0.05, ~10% below 0.10, etc.
- Under-calibrated (liberal): More small p-values than expected
- Over-calibrated (conservative): Fewer small p-values than expected

**Stratification**: Perform this analysis separately for:
- Each degree category
- Each path length
- Each metapath
- Each p-value method (gamma-hurdle vs empirical)

#### Analysis 2: Positive Control - True Hetionet vs Permutations

**Hypothesis**: The true Hetionet graph contains biological signal that differs from random permutations, which should be detectable as an enrichment of low p-values compared to the null test.

**Test**:
1. For each sampled path, compare p-values from:
   - Scenario A (permutation 0 vs permutations 1-20): Expected uniform p-values
   - Scenario B (true Hetionet vs permutations 1-20): Potentially enriched low p-values

2. Assess enrichment:
   - Compare p-value distributions between scenarios (KS test)
   - Count proportion of p-values < 0.05 in each scenario
   - Identify paths with significantly lower p-values in true Hetionet

3. Degree and path length stratification:
   - Does biological signal vary by degree category?
   - Does biological signal vary by path length?

**Expected outcomes**:
- If biological signal exists: True Hetionet should show more p-values < 0.05 than permutation 0 (> 5%)
- Signal may be stronger for certain metapaths (e.g., disease-gene associations)
- Signal may be stronger for shorter paths (less noise accumulation)
- High-degree nodes may show different patterns (hubs in biological networks)

**Visualization**:
- Side-by-side histograms: p-value distributions for Scenario A vs B
- Scatter plot: p-values from Scenario A vs B for same paths
- Enrichment heatmap: proportion p < 0.05 by degree category for each scenario
- Volcano plot: -log10(p-value) vs log(observed/null mean) for true Hetionet

**Interpretation**: This analysis serves multiple purposes:
1. Validates that the methodology can detect true signal when it exists
2. Provides insights into which degree/length combinations are most informative biologically
3. Confirms that permutations appropriately represent a biological null hypothesis
4. Identifies whether our variance observations (more variance = less reliability) hold for real data

#### Analysis 3: Degree Effects on P-Value Reliability

**Hypothesis**: P-value calibration degrades for high-degree node pairs due to increased variance.

**Test**:
1. For each degree category, compute calibration metrics:
   - Proportion of p-values < 0.05 (should be 0.05 if calibrated)
   - Mean absolute deviation from uniformity
   - KS statistic for uniformity test

2. Test for trend across degree categories:
   - Order categories: Low-Low → Medium-Medium → High-High
   - Test for monotonic trend in calibration quality
   - Spearman correlation between degree sum and calibration error

**Visualization**:
- Faceted histograms: p-value distribution for each degree category
- Heatmap: 9x9 grid showing calibration quality for all degree combinations
- Scatter: degree sum (source + target) vs p-value

#### Analysis 4: Path Length Effects

**Hypothesis**: P-value calibration degrades with path length due to increased variance and compositional errors.

**Test**:
1. Compare calibration metrics across path lengths (3, 4, 5)
2. Test for monotonic degradation
3. Quantify variance in null distributions by path length

**Visualization**:
- Side-by-side p-value histograms for length 3, 4, 5
- Box plots of null DWPC variance by path length
- Calibration error vs path length

#### Analysis 5: Variance-P-Value Relationship

**Hypothesis**: Degree categories with higher null distribution variance should show wider p-value distributions (more extreme values possible) but potentially worse calibration.

**Test**:
1. For each degree category, compute null distribution variance
2. For each category, compute p-value distribution properties
3. Correlate variance with:
   - Calibration error
   - P-value distribution variance
   - Proportion of significant p-values

**Visualization**:
- Scatter: null variance vs calibration error
- Scatter: null variance vs % p-values < 0.05

#### Analysis 6: Sample Size Requirements

**Hypothesis**: Degree-grouping provides sufficient sample size for stable p-value estimates, but requirements may vary by degree and path length.

**Test**:
1. For each degree category, record:
   - Number of degree-grouped null DWPCs
   - Calibration quality
2. Subsample null DWPCs (e.g., 50, 100, 200, 500, 1000) and recompute p-values
3. Assess stability: how does calibration change with sample size?

**Visualization**:
- Learning curve: calibration error vs null sample size
- Heatmap: minimum sample size needed for good calibration by degree category and path length

### Secondary Analyses

#### Analysis 7: Comparison of P-Value Methods

Compare gamma-hurdle vs empirical vs direct methods:

1. Correlation between p-values from different methods
2. Calibration quality for each method

This tells us whether the parametric modeling adds value beyond simple empirical p-values.

#### Analysis 8: Gamma-Hurdle Goodness of Fit

- Investigate node-pair-specific null distributions (no degree-grouping)

- Consider alternative metrics beyond DWPC

### Specific Diagnostic Patterns

**Pattern 1**: Good calibration for low-degree, poor for high-degree
- **Implication**: Degree-grouping may not account for heterogeneity within degree groups
- **Action**: Finer degree stratification, or include additional node properties

**Pattern 2**: Good calibration for short paths, poor for long paths
- **Implication**: Compositional errors accumulate with path length
- **Action**: Path-length-specific null models, or non-compositional approaches

**Pattern 3**: Gamma fit poor but empirical p-values well-calibrated
- **Implication**: Parametric assumption wrong, but degree-grouping works
- **Action**: Use empirical p-values instead of gamma-hurdle

- **Implication**: Fundamental issue with degree-grouping assumption
- **Action**: Rethink approach, possibly node-pair-specific nulls

## Limitations and Considerations

### Statistical Limitations

1. **Finite Sample Size**: With only 20 permutations in Phase 1, we have limited power to detect subtle calibration issues. Phase 2 with 200 permutations will be more definitive.

2. **Multiple Testing**: We are conducting many comparisons (9 degree categories × 6 metapaths × 3 methods = 162 combinations). Some "significant" findings may be spurious. Will need multiple testing correction in analysis.

3. **Sampling Variability**: Sampling 100 paths per category introduces randomness. May need to repeat sampling or increase N to ensure robust conclusions.

4. **Degree-Grouping Heterogeneity**: Even within a degree category, nodes may vary in other properties (e.g., biological function, network position) that affect connectivity. Degree-grouping assumes all nodes with the same degree are equivalent.

### Methodological Limitations

1. **Circular Validation**: We're using permutations to validate a permutation-based method. This tests internal consistency but not absolute correctness. The true null hypothesis (no biological relationship) may differ from the permutation null.

2. **XSwap Convergence**: XSwap permutations may not be fully independent. The paper attempted 10× swaps per edge, which may not guarantee convergence to the uniform distribution over all degree-preserving networks.

3. **Metapath Selection Bias**: We're testing only 6 metapaths. Results may not generalize to all 2,205 metapaths in the paper. However, these 6 span a range of characteristics.

4. **Real vs Permuted**: Real biological networks have structure (modules, pathways, disease mechanisms) that permutations destroy. Null distributions from permutations may not reflect the appropriate null for biological hypotheses.

### Practical Limitations

1. **Computational Cost**: Even Phase 1 may take several hours. Phase 2 will require HPC resources. This limits iteration speed.

2. **Data Availability**: We have 200 permutations available. Some analyses might benefit from even more, but generating new permutations is computationally expensive.

3. **Biological Ground Truth**: We lack true labels for whether connectivity is biologically meaningful. We can only assess statistical calibration, not biological validity.
