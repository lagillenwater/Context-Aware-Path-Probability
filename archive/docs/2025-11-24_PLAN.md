# DWPC P-Value Calibration Repair - Analysis Plan

**Date:** 2025-11-24
**Status:** Proposed - Awaiting approval before implementation

## Context and Motivation

This morning's diagnostic analysis revealed that the gamma-hurdle method-of-moments approach for calculating p-values is systematically failing. The critical evidence is that Permutation 0 (a randomly permuted network) shows mean p-value of 0.741 when compared to permutations 1-20, despite being generated by the same process. Under correct calibration, we would expect mean_p ≈ 0.50 since all 21 permutations are equivalent.

This calibration failure has several consequences. First, it makes it impossible to detect biological signal in the true Hetionet network, which shows nearly identical mean p-value (0.729) to Permutation 0. Second, the failure scales dramatically with path length and node degree - short paths with low-degree nodes show moderate miscalibration (mean_p = 0.3-0.5), while long 5-node paths with high-degree nodes show complete failure (mean_p = 1.0 for all samples). Third, the method-of-moments parameter estimation appears to be biased when fitting gamma distributions to high-variance DWPC distributions, producing parameters that don't accurately represent the empirical null distribution.

The fundamental question we need to answer today is: **Can we achieve proper p-value calibration using alternative methods, and if so, which method provides the best balance of calibration quality, statistical power, and computational efficiency?**

## Priority 1: Implement and Validate Empirical Percentile Method

### Rationale

The empirical percentile method is the most straightforward non-parametric approach to p-value calculation. It makes no distributional assumptions and is guaranteed to produce correct calibration if the null distribution is representative. The calculation is simple: for each observed DWPC value, count how many null values (from permutations 1-20) are greater than or equal to the observed value, then divide by the total number of null samples.

We currently have 20 permutations × 100 samples per degree category = 2,000 null samples per category. This provides sufficient resolution for p-values down to 0.0005 (1/2000), which is adequate for most applications. The method requires no parameter fitting, eliminating the bias we've observed with method-of-moments.

### Implementation Plan

**Step 1: Add empirical percentile function to codebase**

Modify `src/dwpc_pvalue_validation/pvalue_calculation.py` to add:

```python
def calculate_empirical_pvalue(observed, null_distribution):
    """
    Calculate p-value as empirical percentile.

    Args:
        observed: Single DWPC value or array of values
        null_distribution: Array of null DWPC values from permutations

    Returns:
        p-value(s): Proportion of null values >= observed
    """
    null_array = np.array(null_distribution)

    if np.isscalar(observed):
        return (null_array >= observed).sum() / len(null_array)
    else:
        observed_array = np.array(observed)
        pvalues = np.zeros(len(observed_array))
        for i, obs in enumerate(observed_array):
            pvalues[i] = (null_array >= obs).sum() / len(null_array)
        return pvalues
```

This function will be added alongside the existing `calculate_pvalue_gamma_hurdle()` function, allowing direct comparison.

**Step 2: Modify experiment.py to support both methods**

Update `src/dwpc_pvalue_validation/experiment.py` to add a `method` parameter to `run_scenario_a()` and `run_scenario_b()` functions. When `method='empirical'`, use the new empirical percentile function instead of gamma-hurdle. Save results with method name in filename (e.g., `CbGpPW_scenario_a_empirical.npz`).

### Validation Criteria

**Primary criterion:** Permutation 0 calibration
- **Success:** Mean p-value for Permutation 0 between 0.45 and 0.55 across all metapaths
- **Acceptable:** Mean p-value between 0.40 and 0.60
- **Failure:** Mean p-value outside 0.40-0.60 (would indicate empirical method also failing)

**Secondary criteria:**
- Kolmogorov-Smirnov test should not strongly reject uniformity (p > 0.05 preferred, p > 0.01 acceptable)
- No systematic degree-dependent bias (high-degree and low-degree categories should have similar mean p-values)
- No path-length-dependent bias (3-node, 4-node, and 5-node paths should have similar calibration)

If these criteria are met, we can conclude the empirical percentile method provides proper calibration and the gamma-hurdle failures were due to parametric fitting issues.

## Priority 4: Alternative Parametric Methods (If Empirical Insufficient)

### Rationale

Empirical percentile method has limitations: coarse p-values (minimum 1/2000 = 0.0005) and requires many null samples. If empirical method succeeds but we want finer resolution or if it fails due to insufficient samples, parametric methods become attractive again.

### Proposed Alternatives to Test

**Option A: Log-normal distribution**

DWPC values are positive and right-skewed, making log-normal a natural choice. Fit to log(DWPC) values:

```python
log_dwpcs = np.log(dwpcs[dwpcs > 0])
mu, sigma = log_dwpcs.mean(), log_dwpcs.std()
pvalue = lognorm.sf(observed, s=sigma, scale=np.exp(mu))
```

**Option B: Maximum likelihood estimation for gamma**

Replace method-of-moments with numerical MLE:

```python
from scipy.optimize import minimize

def gamma_negloglik(params, data):
    alpha, beta = params
    return -np.sum(gamma.logpdf(data, alpha, scale=beta))

result = minimize(gamma_negloglik, x0=[1.0, 1.0], args=(dwpcs,))
alpha_mle, beta_mle = result.x
```

MLE is more robust to outliers and should produce better fits than method-of-moments.

**Option C: Weibull distribution**

Flexible distribution for positive data with adjustable shape:

```python
shape, loc, scale = weibull_min.fit(dwpcs, floc=0)
pvalue = weibull_min.sf(observed, shape, loc=0, scale=scale)
```

### Testing Protocol

For each alternative:
1. Implement in `pvalue_calculation.py` as separate function
2. Run quick test locally (5 perms, 20 samples)
3. Check Permutation 0 calibration
4. If promising, run full HPC validation
5. Compare calibration quality, computational cost, and statistical power

### Decision Criteria

Select method based on:
- **Calibration quality:** Permutation 0 mean_p closest to 0.50
- **Robustness:** Consistent performance across degree categories and path lengths
- **Power:** Ability to detect biological signal (Hetionet different from Permutation 0)
- **Computational cost:** Runtime for 6 metapaths × 100 samples × 20 perms
- **Interpretability:** Ease of explaining to reviewers/readers

Empirical percentile is likely best unless it fails validation or proves insufficient for some reason.
